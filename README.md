# fisibox-hall-of-fame
Hodnotenie hier pre Fiši box
FiŠi-box Hall of Fame je súčasť rodinného retro projektu FiŠi-box.

Pomáha objavovať nové hry, vytvárať spoločný TOP 10 rebríček a uchovávať herné spomienky Filipka, Šimonka a celej rodiny.

Nie je to o technológii. Je to o hrách, ktoré si budeme pamätať aj o 30 rokov.
